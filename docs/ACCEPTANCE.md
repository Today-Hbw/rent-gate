# 第一阶段交付与验收

## 本阶段范围

采用单体 Spring Boot 3.5 / Java 17+ 服务，内置响应式管理页与登录页，H2 文件库存储，无需单独部署前端或数据库。设备固件使用 Arduino / ESP8266 / PlatformIO。

已实现：

- 设备登记、独立随机密钥、密钥摘要存储与重置。
- 手动开机默认 30 分钟，可调整为 1–1440 分钟；重复放行覆盖原到期时间。
- 手动停止、持久化状态、每秒过期状态更新、3 秒轮询。
- 后台在线/离线、剩余时间、心跳与继电器上报显示；手机使用设备卡片。
- `POST /poll` 返回 `action`、`expire_ts`、`server_ts`、`remaining_seconds`。
- WiFiManager 配置 WiFi、服务器、设备编号、设备密钥，LittleFS 持久化自定义配置。
- 固件上电默认断开、低电平继电器控制、本地独立计时、断网继续计时、同一放行不会被轮询续时。
- 订单表预建，所有手动操作不生成订单。
- 管理登录、Session、CSRF、设备密钥校验、参数校验、事务行锁。
- Maven Wrapper、Docker 配置、GitHub Actions、无硬件模拟器及操作文档。

未包含：真实支付、退款、商户进件、多级账号、商户隔离、套餐配置、免费试用/冷却、客人扫码付款页、OTA。这些属于 PRD 第二阶段。

## 实物验收清单（需接入硬件）

- [ ] 烧录固件，在继电器底板上独立 5V 供电。
- [ ] 验证底板实际控制 GPIO / 吸合电平与固件配置相符。
- [ ] 手机连接配网热点，填服务器地址、WiFi 和设备凭据。
- [ ] 确认后台显示在线，继电器初始断开。
- [ ] 放行 1 分钟，确认吸合、到期断开，后台上报一致。
- [ ] 放行后下发停止，确认下一次轮询断开。
- [ ] 运行中关闭 WiFi，确认本地到期断开；恢复后重新轮询。
- [ ] 运行中重启 ESP，确认启动先断开，联网后恢复未到期指令。
- [ ] 断电重启后无需重新输入设备配置；串口 `c` 可重新配网。
- [ ] 检查启动瞬态、继电器抖动和电源稳定性。

编译与模拟测试不代表上述实物项目已经验收；设备到货后按清单完成低压测试，再安排合规的负载接线。
