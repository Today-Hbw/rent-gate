连接与演示指南

  1. 登记设备

    点击“添加设备”，保存设备编号和一次性密钥。

  2. 烧录并配网

    将 firmware 固件烧入 ESP-01S。连接 RentGate-xxxxxx 热点，在 192.168.4.1 填 WiFi、服务器 HTTP 地址、编号和密钥。

  3. 确认在线

    电脑与设备需要网络互通。服务器地址填写设备可访问的局域网 IP，不能填写 localhost。成功轮询后状态变为在线。

  4. 验证开关与倒计时

    先用 5V 继电器灯验证。设置 1 分钟并放行，确认继电器吸合，倒计时结束后断开。也可点击“停止”下发断电指令。

离线设备仍可接收放行记录，实际指令在恢复轮询后生效。停止指令也需网络恢复后才能送达。
