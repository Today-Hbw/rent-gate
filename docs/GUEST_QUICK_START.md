# 扫码使用设备

**当前提供免费试用，暂不支持扫码付款。**

## 三步开始

1. **扫机身二维码**：用手机扫描，核对页面上的门店和桌号或设备名称。
2. **点免费试用**：按钮可以点击时，点“免费试用 × 分钟”。无需注册或登录。
3. **等机器通电**：看到“开机指令已发送”后稍等，机器收到后启动；页面显示剩余使用时间。

**到期自动断电，无需在手机上结束。**

## 按钮不能点时

| 页面提示 | 请这样处理 |
| --- | --- |
| 设备使用中 | 等本次使用结束，或联系老板 |
| 冷却中，暂不可试用 | 查看“距离下次试用”，等候或联系老板 |
| 设备离线、等待网络恢复 | 检查手机网络；仍不能使用请联系老板 |
| 设备入口不可用、暂未开放试用 | 联系老板确认 |

免费试用按每台机器计算，换手机或重新扫码不会重新获得时长。

页面上的套餐目前只供展示，选择套餐不会扣款或增加时间。其他使用安排请联系老板。

机器没有启动、需要提前停止或遇到其他问题，请找现场工作人员。客人无需连接 RentGate 配置热点，无需填写密码或配对验证码。
