# 操作手册

## 管理员

使用 admin 登录。“账号与权限”先创建服务商，再创建归属于服务商的普通用户（老板）。密码由创建者设置并私下交给使用人；登录后可在“个人设置”改密码。密码不会在列表显示，忘记时由上级重置。

“设备类型”维护通用或服务商专属类型。配置免费试用和试用结束后冷却分钟数；试用为 0 关闭新试用。修改规则不改变已下发的截止时间与冷却。

“设备控制台”添加设备并选择老板；运行中的设备先停止，再更换老板/类型。旧设备可重新分配，原老板历史订单仍归原老板。密钥仅显示一次，请关闭窗口前保存并填入硬件配网。

“系统设置”修改客人站点名、提示、在线判定秒数。不要把密码或设备密钥放入公开文案。

## 服务商

仅管理自己与名下老板。可创建/停用老板、重置老板密码，不能创建服务商或管理员。维护自己及老板商户资料，为老板添加设备、套餐并查询订单收益。

可创建服务商自己的设备类型，名下老板可使用这些类型与平台通用类型；通用类型只读。

## 老板

管理自己的商户名、小微商户号、设备及套餐。套餐按设备类型配置时长和价格，同类型可有多个套餐，停用后客人页不再展示。价格目前只展示，不能付款。

设备操作包含放行、停止、编辑、二维码、重设密钥。放行默认 30 分钟，可改 1–1440；重复放行从当前时刻重新计算，可能缩短剩余时间。停止/停用在设备下一次成功轮询后执行。

订单可按设备、状态与日期过滤。收益仅统计真实已支付订单；试用/手动操作无收入，新库为 0。

## 客人扫码

下载设备二维码并贴在机身。客人手机打开后可见商户、机器、状态、试用规则和套餐。设备在线、空闲、冷却结束时可领免费试用。成功后显示倒计时和指令已发送，设备收到后启动。

试用结束自动断电并进入冷却。默认 15 分钟试用 + 120 分钟冷却，开始后第 135 分钟可再领。资格绑定设备，换手机或刷新不会重置。

## 常见问题

| 现象 | 检查 |
| --- | --- |
| 扫码打不开 | URL 不能是 localhost/127.0.0.1。设置 RENT_GATE_PUBLIC_BASE_URL 后重新生成；确认手机可达服务器端口。 |
| 设备离线 | 检查配网、设备编号、密钥和服务器地址。无硬件时运行 scripts/simulate_device.py。 |
| 在线仍不可试用 | 检查设备是否分配老板、账号/类型启用、试用分钟大于 0、设备空闲且冷却结束。 |
| 显示运行但未通电 | 运行表示有效服务器指令。看心跳与继电器回报，检查低压硬件与有效电平。 |
| 老板看不到设备 | 上级检查设备归属；历史未分配设备仅管理员可见。 |
| 改密码后失效 | 正常；旧会话失效，使用新密码重新登录。 |
| 重启密码与环境变量不同 | 初始化后使用数据库中的密码，变量不再覆盖修改后的密码。 |
| 付款不能点击 | 本版未接支付，可试用或后台手动放行。 |

烧录与配网见 [固件说明](../firmware/README.md)。数据库、备份和升级见 [部署说明](DEPLOYMENT.md)。

硬件仅烧录需要电脑。首次上电自动打开 `RentGate-xxxxxx` 热点，手机使用固定密码 **`RentGate888`** 连接后访问 **`http://192.168.4.1`** 配网。以后连续约 30 秒连不上原 WiFi，也会自动打开热点；用手机选择新 WiFi 并保存即可，保留预填的设备编号、密钥和服务器地址。后台轮换设备密钥后，硬件收到认证失败会自动开热点，手机更新密钥即可。
