# Rent Gate 设备租赁系统操作说明书

适用版本：管理后台及设备程序 v0.3.1。更新日期：2026 年 10 月 27 日。

面向门店老板、服务商和平台管理员。“后台”是登录后管理设备的网页；“客人页”是扫描机身二维码打开的网页；“配网”是让设备连接店里的 WiFi。

**使用前先了解：本版支持免费试用和后台手动开机，尚未开通扫码付款。** 套餐价格仅供展示，填写商户号不会开通收款。试用和手动开机不会产生收费订单或收益，也不能用本系统核对店内另外收取的钱款。

## 1. 登录与账号

### 1.1 第一次登录

先向交付人员领取三项信息：**后台网址、登录账号、初始密码**。后台网址由交付人员提供，本文不提供通用登录地址。

1. 用手机或电脑浏览器打开后台网址。
2. 填写“登录账号”和“密码”，点击“登录控制台 →”。
3. 登录后，核对页面右上角的姓名和角色。
4. 点击左侧“个人设置”，核对“所属服务商”。老板发现上级不对时，先联系交付人员。

**完成标志：** 能打开“设备控制台”，姓名和角色符合本人身份。老板只应看到自己名下的设备；没有设备时，先让服务商确认是否已分配。

### 1.2 修改密码与退出

1. 点击“个人设置”。
2. 在“登录密码”区域填写“当前密码”和“新密码”。新密码用 8–64 个字符，建议使用英文字母、数字组合。
3. 点击“修改密码”。页面回到登录页后，用新密码重新登录。
4. 使用完毕，点击页面右上角“退出”。

忘记密码时：老板联系所属服务商，服务商联系平台管理员。管理员忘记密码需联系系统维护人员。页面没有短信找回密码功能。

密码被上级重置、账号被停用或登录过期时，原登录可能失效；重新登录仍失败，再联系上级。不要把登录密码、配对验证码或设备密钥发给客人。

## 2. 老板日常使用

### 2.1 开店先看设备是否正常

打开“设备控制台”，按设备名称、编号或老板名称搜索，也可在“状态”中选“离线”“运行中”等条件。

| 页面内容 | 含义 | 你应怎样判断 |
| --- | --- | --- |
| 设备名称、编号 | 例如“一号桌”和 table-01，用于区分机器 | 操作前先核对机器，避免关错桌 |
| 归属 / 类型 | 机器属于谁，使用哪套试用规则 | 应当是本店老板及正确的设备类型 |
| 在线 / 离线 | 设备最近是否与系统保持联系 | 在线才能及时接收新指令；离线先查供电和 WiFi |
| 心跳 | 设备上一次向系统报到的时间 | 时间长期不更新，连接可能有问题 |
| 待机 | 系统当前没有有效的开机安排 | 通常应处于断电等待状态 |
| 试用中 / 手动运行 | 系统已安排本次使用时间 | 下方显示本次剩余时间 |
| 继电器回报：通电 / 断电 | 控制盒最近报告的通断电情况 | 结合报到时间及机器实际反应一起确认 |
| 已停用 | 该设备已被暂停使用 | 客人扫码入口不可用，需有权限的人恢复启用 |

**“在线”“指令已发送”或“手动运行”都不能单独证明机器已开机。** 页面会自动更新；下达指令后要看最新“继电器回报”，并确认机器实际能用。回报也可能因断网停留在旧状态。

### 2.2 手动开机：点击“放行”

适用于店内安排使用、测试机器等场景。“放行”就是允许这台机器通电一段时间。

1. 在“设备控制台”找到机器，核对名称和编号。
2. 在设备列表上方“放行时长”填写分钟数，可填 **1–1440 的整数**，默认是 30 分钟。
3. 点击该机器所在行的“放行”。正在运行的设备会弹出确认提示，读清楚后再确认。
4. 等待页面更新。正常连接时，设备通常在约 3 秒后的下一次联络收到指令，网络较慢时可能更久。
5. 确认显示“手动运行”和剩余时间，最新“继电器回报”为“通电”，现场机器可以使用。

**重复点“放行”会从这次点击重新计时，不会把时间累加。** 例如原来还剩 50 分钟，此时放行 30 分钟，剩余时间会改为约 30 分钟，反而缩短。要让机器从现在起再用 1 小时，应填写 60 分钟。

离线时也可能保存手动指令，但机器当时收不到；恢复连接后只执行尚未到期的剩余时间。例如放行 30 分钟，过 10 分钟才联网，就只剩约 20 分钟。希望客人获得完整时长时，先恢复在线，再确认放行时间。

提示“设备正在配网或配对”时，先完成或取消该操作，再开机，见[首次连接设备](#pairing)和[更换 WiFi](#wifi)。

### 2.3 提前结束：点击“停止”

1. 核对要停止的机器及现场使用情况。
2. 点击该行“停止”，在提示框中确认。
3. 等设备重新与后台联络后，检查页面变为“待机”、最新回报为“断电”，现场机器已停止供电。

停止后不会自动补回剩余使用时间，也不会清除试用冷却。**离线设备无法立即收到停止指令**；需要现场立即停止供电时，使用机器正常电源开关，由店内人员处理。

### 2.4 暂停对外使用：停用设备

设备维修、撤走或暂不让客人使用时：

1. 找到设备，点击“编辑”。
2. 取消勾选“启用设备”，点击“保存”，确认停用提示。
3. 确认设备行显示“已停用”，客人扫码入口无法使用。原开机安排会被取消，断电指令仍需设备收到后才能执行。
4. 恢复使用时，再次“编辑”，勾选“启用设备”并保存。

“停止”只结束当前这次使用，符合条件时客人仍可领试用；“停用”同时关闭这台设备的客人入口。恢复启用后，需要使用时重新放行或按条件领取试用。

### 2.5 下载、张贴与更换二维码

1. 在设备行点击“二维码”，核对弹窗中的设备名称和编号。
2. 点击“下载二维码”，将图片打印或交给打印人员。建议同时标注桌号，避免贴错。
3. **贴到机身前，先用客人的手机实际扫描一次**，确认能打开页面、显示正确门店和设备。
4. 每台设备张贴自己的二维码，并附上[客人使用卡](GUEST_QUICK_START.md)及店内联系方式。

同一台设备修改名称或门店名称后，客人页会显示最新信息，通常无需重打二维码。如果换成后台新建的另一台设备记录，或维护人员更改了客人页面网址，需要重新下载、测试和张贴。

如弹窗提示“当前地址仅本机可访问”，不要继续批量打印。把提示交给服务商或系统维护人员，修正访问地址后重新下载；无需自己填写服务器参数。

### 2.6 修改客人看到的门店名称

1. 点击“商户资料”，找到自己的记录，点击“编辑”。
2. 在“商户名称”填写对客人展示的门店名称，例如“好运棋牌室”。
3. 商户号只填写服务商确认过的编号；尚未取得时可留空，不影响本版免费试用。
4. 点击“保存”，再扫描二维码检查名称。

没有单独设置门店名称时，页面会使用老板账号的显示名称。后台的“显示名称”和“商户名称”是两项不同资料；单独保存过的门店名称不会因老板显示名称改变而自动变化。

本页仅保存资料，不能申请商户号、绑定银行卡或开通支付。不要在名称等文本框里填写银行卡密码、支付密码或支付密钥。

### 2.7 设置展示套餐

1. 点击“时长套餐” → “＋ 添加套餐”。
2. 核对“所属老板”，选择“设备类型”。老板账号的归属固定为自己。
3. 填写“套餐名称”“使用时长（分钟）”和“展示价格（元）”。例如“1 小时”、60 分钟、10 元。
4. 勾选“启用套餐”，点击“保存”。
5. 扫描相同类型设备的二维码，确认展示内容。要下架套餐，在其“编辑”中取消“启用套餐”并保存。

**套餐按“老板 + 设备类型”共用，不是每台机器单独定价。** 本店同类型设备会显示同一组启用套餐。时长为 1–1440 整数分钟，价格以元填写。

本版客人可以查看和选择套餐，但“支付暂未开通”按钮不可点击。添加套餐不会改变免费试用时长；试用规则由服务商或管理员在“设备类型”中维护。

### 2.8 看订单与收益

“订单查询”中可填写设备编号、选择状态和开始/结束日期，再点击“查询”；记录较多时点“上一页”“下一页”。这里只能查看，不能补建订单或操作退款。

“收益统计”显示已支付订单的金额、数量和最近 7 日收益。“今日”按**北京时间当天 00:00**起算。

**当前版本不会创建支付订单。** 免费试用、后台放行、在店内另行收款，都不会记入这里。没有历史支付记录时，订单为空、收益为 0 是正常情况。界面提供的“已退款”等筛选项只用于查询已有记录，不代表已开放退款功能。

### 2.9 修改设备名称

在“设备控制台”找到设备，点击“编辑”，修改“设备名称”并保存，再扫描二维码核对。例如桌号从“一号桌”改成“大厅一号桌”，只需改名称。

“设备编号”创建后不能修改。更改设备类型需先停止机器；老板只能选择自己可用的类型，不能修改设备所属老板。需要调整归属时联系服务商。

## 3. 服务商：为新门店开通并交付

建议顺序：**创建老板账号 → 确认试用规则 → 添加设备 → 手机连接设备 → 实际开关机验证 → 测试二维码 → 交给老板。** 商户名称和展示套餐可在交付前补齐。填写商户号不是本版试用的前提。

### 3.1 创建老板账号

1. 登录自己的服务商账号，点击“账号与权限” → “＋ 创建账号”。
2. 填写“登录账号”，使用 3–40 个字符，以英文字母、数字或下划线开头，其后还可用英文句点和短横线。例如 haoyun01。
3. 填写“显示名称”，建议能清楚识别门店或负责人。
4. 角色为“普通用户（老板）”；所属服务商为当前服务商。
5. 设置 8–64 个字符的初始密码，点击“保存”。
6. 在列表核对账号、角色、上级和启用状态，将后台网址、账号、初始密码私下交给老板，提醒首次登录后修改密码。

账号创建后不能修改登录账号、角色或所属服务商。选错时先联系平台管理员处理，避免继续分配设备。服务商不能创建另一个服务商或管理员。

### 3.2 确认免费试用规则

1. 点击“设备类型”。若已有适用的启用类型，可直接使用。
2. 需要专用规则时，点击“＋ 添加类型”，填写“类型名称”“免费试用（分钟）”“试用结束后冷却（分钟）”，勾选“启用类型”，保存。
3. 服务商创建的类型供自己名下老板使用；“平台通用”类型可以查看，修改需联系管理员。

这里的“设备类型”也决定试用规则。修改某类型，会影响所有使用该类型设备今后领取的试用；要只调整部分设备，应另建类型，再在设备停止后修改类型。

| 设置 | 作用 |
| --- | --- |
| 免费试用 15、冷却 120 | 每次试用 15 分钟，本次计划结束后再等 120 分钟 |
| 免费试用 0 | 关闭该类型的新试用，后台仍可按权限手动放行 |
| 冷却 0 | 本次使用结束且设备符合其他条件时，可再次领取试用 |

例如 14:00 开始试用，15 分钟到 14:15；冷却 120 分钟后，最早 16:15 才能再领。冷却针对**同一台设备**，换手机不会重新获得试用。

提前停止或手动放行都不会清掉已经记录的冷却。修改类型规则只影响后续新试用，不改变已安排的使用截止时间或已记录的冷却结束时间。试用时长可设 0–1440 分钟，冷却可设 0–10080 分钟。

### 3.3 添加设备并分配给老板

先确认手里有已由交付人员安装好程序的控制盒，并已完成接线检查。普通使用者无需拆机或给控制盒安装程序。

1. 点击“设备控制台” → “＋ 添加设备”。
2. 填写“设备编号”：1–64 个英文字母、数字、下划线或短横线。例如 haoyun-01。编号创建后不能修改。
3. 填写容易辨认的“设备名称”，例如“好运棋牌室一号桌”。
4. 选择正确的“所属老板”和启用的“设备类型”，点击“保存”。
5. 保存后可能弹出“设备连接凭据”。使用验证码配对时可关闭该窗口，继续[第 4 节](#pairing)。

**完成标志：** 列表出现该设备，归属、类型正确。新设备尚未连接时显示离线是正常现象。

老板也可以在自己的权限内添加设备，归属固定为自己。管理员可暂不分配老板，但未分配设备不能开放客人试用；交付前必须分配。

不要把同一个后台设备编号配给两台实体机器；每台机器应有独立记录和二维码。多台同时安装时，一次只处理一台，并核对热点页面和后台的“硬件”标识；该标识也称 MAC，用来区分控制盒。

### 3.4 交付前逐项确认

- [ ] 老板能用自己的账号登录，只能看到本店设备。
- [ ] 每台机器的名称、编号、归属、类型与现场一致。
- [ ] 设备在线，按[2.2](#daily)放行后，现场确实通电；停止后确实断电。
- [ ] 完成一次到期自动断电的实机验证，不能只看网页倒计时。
- [ ] 每个二维码用老板或客人的手机测试，显示正确设备；计划对外使用手机流量时，也用流量测试可访问。
- [ ] 符合条件时能领取免费试用，结束后出现冷却提示。测试领取也会触发冷却，安排好测试时间。
- [ ] 已向老板说明支付未开通、手动放行不累计时长、离线停止不能立即生效。
- [ ] 已交付后台网址、账号、门店 WiFi 信息及售后联系人。

<a id="pairing"></a>

## 4. 首次把实体设备连接到后台

本节适用于 v0.3.1 设备程序。后台设备行的“固件”就是控制盒程序版本；新设备未连接前可能显示“尚未上报”。版本不确定或页面不同，先联系交付人员确认。

### 4.1 操作前准备

准备已添加的后台设备记录、已通电的实体设备、手机，以及门店 **2.4 GHz WiFi** 的名称和密码。只有 5 GHz 的 WiFi 无法供当前控制盒使用，请让店内网络维护人员提供合适的网络。

设备配对时会让手机暂时连接控制盒热点，该热点本身不上互联网。可以先在电脑上打开后台，用手机操作热点；也可以只用一部手机，先记下验证码，再切换网络。

**设备须启用并处于待机。** 正在使用时，先与现场人员确认并停止，再配对。不要拿正在服务客人的机器做安装测试。

### 4.2 用验证码配对

1. 在后台“设备控制台”找到这台设备，点击“配对”，记下 **8 位数字验证码**及有效时间。验证码 5 分钟有效，要保留开头的 0；重新生成后旧码失效。
2. 首次使用时，控制盒通电后会打开名为 **RentGate-xxxxxx** 的 WiFi 热点，后缀因设备而异。已在线的设备要重新配对时，还需点击“进入配网”让它打开热点；**点“配对”只生成验证码，不会自动打开热点**。
3. 打开手机的 WiFi 设置，连接对应热点，密码为 **RentGate888**。手机提示“无互联网连接”时，选择继续连接。
4. 打开手机浏览器，在地址栏输入 **http://192.168.4.1**。这是设备的配置网址，只有连接该热点时才可使用。
5. 在“设备配对”首页填写“WiFi 名称”“WiFi 密码”和“配对验证码”。WiFi 名称填写店里的网络名称，不是 RentGate-xxxxxx。同一个 WiFi 的密码留空可沿用原密码；首次连接或换网络时应填入正确密码。
6. 点击“保存并关闭热点”。热点消失、手机暂时打不开这个配置页是正常现象，设备正在连接店里的网络并完成配对。
7. 将手机切回店内正常 WiFi 或手机流量，重新打开后台，等待设备显示在线。
8. 核对名称、编号和硬件标识，再按[2.2](#daily)放行验证现场机器，随后停止。

**完成标志：后台显示正确设备在线，并且实体机器能按指令通电和断电。** “已保存”只说明请求保存了，不等于已连接成功；配网页显示“本地配置（待认证）”也不能当成成功。

配对失败时，设备会重新打开热点。重新连接热点，检查 WiFi 信息和验证码；过期就回后台生成新码再试。这个流程无需返回后台再确认配对。

### 4.3 暂时不继续配对

配网页点击“取消并关闭热点”。后台生成的验证码不再使用时，在“配对”弹窗点击“作废验证码”；仅关闭弹窗不会立即作废验证码。

配网页连续 3 分钟没有输入、点选等操作会自动关闭；仅让页面开着不会一直延长时间。之后仍连接失败时，设备可能再次打开热点。

### 4.4 何时需要“手动配置（Config）”

通常使用首页验证码配对。以下情况改用“手动配置（Config）”：只更换 WiFi、交付人员要求修改服务器地址，或需要手动填写设备资料。

手动配置中“服务器 HTTP 地址”“设备编号”“设备密钥”必须对应当前设备；不知道时向交付人员索取，不要猜填。当前控制盒只接受以 http:// 开头的服务器地址，不能直接照抄可能以 https:// 开头的后台登录网址。

重新配对成功会使原设备密钥失效。不要用同一条后台设备记录给另一台机器配对，否则原机器可能无法继续联络后台。

<a id="platform"></a>

## 5. 平台管理员

### 5.1 开通服务商

1. 使用管理员账号登录，点击“账号与权限” → “＋ 创建账号”。
2. 填写“登录账号”“显示名称”，将角色选为“服务商”，设置初始密码，保存。服务商不需要选择上级。
3. 在账号列表核对角色和启用状态，将后台网址与账号资料私下交接。
4. 由服务商按[第 3 节](#delivery)创建名下老板。管理员也可代建老板，但须选对所属服务商。

界面不提供新建管理员的入口。服务商账号及老板账号的角色、所属服务商创建后固定，不能直接跨服务商转移账号。

### 5.2 重置密码与停用账号

老板忘记密码时，所属服务商或管理员进入“账号与权限”，点击对应行“重置密码”，填写新密码并保存，私下告知本人。服务商忘记密码，由管理员同样处理。重置后原登录失效。

需要停用时，点击对应账号“编辑”，取消“启用账号”并保存；恢复时重新勾选。停用服务商还会阻止其名下老板登录，以及名下设备的新试用，影响范围较大，操作前核对对象。

**停用账号不等于立刻关闭机器。** 已下发的使用倒计时仍可继续；要停止机器，还需逐台执行“停止”或“停用设备”，并核实设备实际断电。

### 5.3 公共类型与设备调整

在“设备类型”中，管理员可选择“平台通用”或指定服务商。试用和冷却的设置方法见[3.2](#delivery)。

设备需要换老板或类型时，先确认现场已停止，再在设备行“编辑”中修改“所属老板”“设备类型”并保存。服务商只能在自己名下老板范围内分配，老板不能把设备转给别人。新类型必须是目标老板可用的类型；调整后由新老板登录核对并重新扫码验证。历史订单仍归原来的老板。

“删除”类型时，只要还有设备使用就会被阻止；没有设备使用时，删除会一并删除该类型下的时长套餐。只想暂停试用时，优先把试用分钟数改为 0；需要保留资料时可停用类型，避免误删。

### 5.4 系统设置

管理员进入“系统设置”，修改后点击“保存设置”：

| 字段 | 用途与填写建议 |
| --- | --- |
| 站点名称 | 所有客人页面顶部展示的系统名称 |
| 客人提示 | 所有客人页面底部展示的提示，适合写统一使用提醒；门店专属电话建议印在本店使用卡上 |
| 在线判定时间（秒） | 多久没收到设备报到就显示离线，通常保留 12 秒；仅在维护人员指导下调整 |

这里的改动影响全平台，不是单店设置。扩大在线判定时间不会修复断网，只会延后页面显示离线。公开文案中不要写登录密码、WiFi 密码或设备密钥。

## 6. 更换 WiFi 与连接维护

### 6.1 设备在线，准备换网络

1. 先确认机器无人使用。在“设备控制台”点击“停止”，核实现场已停止。
2. 点击该设备的“进入配网”，确认提示，等待出现 RentGate-xxxxxx 热点。
3. 手机连接热点，密码 **RentGate888**，打开 **http://192.168.4.1**。
4. **只换 WiFi、保留原设备绑定时，点击“手动配置（Config）”。** 首页要求验证码，不能只填 WiFi 就提交。
5. 在手动配置页选择或填写新的 WiFi 及密码，保持“配对验证码”为空，保留原“服务器 HTTP 地址”“设备编号”和“设备密钥”。确认这些原有信息都存在；不完整时先联系交付人员，或改按[第 4 节](#pairing)生成新码配对。
6. 保存并关闭热点，将手机切回正常网络；若按钮显示英文“Save”，即为保存。
7. 回到后台等待同一台设备重新在线，确认编号未变，再验证放行和停止。

也可生成新验证码，按首页配对流程换网；这会重新配对并更换设备密钥。只换 WiFi 时通常无需重新配对。

### 6.2 原 WiFi 已断开或密码改变

设备连续约 30 秒连不上原 WiFi 时，会自动打开热点，无需先在后台点击“进入配网”。在设备附近找到热点，按上面的步骤连接并修改。

如果设备已经离线，后台发出的进入或结束配网指令都不能立即送达。现场看不到热点时，确认供电和当前连接的机器；仍无法处理就联系服务商。

### 6.3 退出配网页

- 现场操作：点击“取消并关闭热点”，放弃未保存的修改，设备尝试恢复原配置。
- 后台操作：点击“结束配网”，等待“正在结束配网”消失。设备需能与后台联络；v0.3.0 及更新程序支持后台结束。
- 无人操作：约 3 分钟后自动关闭；设备仍需配置时，之后可能再次打开热点。

如只生成了验证码就决定不操作，在“配对”弹窗点击“作废验证码”。未完成的配对会暂时阻止新开机指令，关闭弹窗不会取消它。

### 6.4 “查看密钥”和“重设密钥”

设备密钥是控制盒连接后台用的专用密码，**不是后台登录密码、WiFi 密码，也不是客人要填的信息**。

“查看密钥”用于交付人员核对或手动配置。旧设备可能暂时不能查看，需成功连接一次，或由交付人员重新配对处理。

“重设密钥”会立即使旧密钥失效，新密钥不会自动送到实体设备。需要更换时，先停止机器并安排现场人员配合，再在设备上手动更新，或生成新验证码重新配对。完成后须确认设备重新在线。不要把重设密钥当成通用的修复按钮，也不要用它代替“停止”。

### 6.5 使用中断网、断电会怎样

设备断网后，**已开始的倒计时仍继续，到期自动断电**；断网时收不到新放行或停止指令，也不能领取新的免费试用。刷新客人页、关闭手机或换手机不会延长使用时间。

设备断电重启后先保持断电，再联网取得仍有效的开机安排；仅恢复尚未到期的剩余时间。原定时间不会因重启重新开始。

## 7. 客人扫码使用

可以把本节单独给客人阅读，或打印[客人使用卡](GUEST_QUICK_START.md)贴在机身旁。

1. 用手机扫描机身上的设备二维码，不需要后台账号，也不需要连接 RentGate 配置热点。
2. 核对门店、桌号或设备名称，查看在线状态和试用规则。
3. “免费试用 × 分钟”按钮可以点击时，点一次即可。
4. 页面出现“开机指令已发送，设备收到后会自动启动”，等待机器通电。正常网络下通常数秒内收到指令；没有启动就联系老板。
5. 使用时查看“剩余使用时间”，到期自动断电，无需在手机上结束。刷新页面不会重新计时。

试用资格按机器计算，不是每个客人各领一次。正在使用、离线、冷却中或未开放试用时，按钮不可点击，按页面提示等待或联系老板。“距离下次试用”是等待时间，不是当前可以使用的剩余时间。

**本版暂不支持扫码付款。** 选择套餐不会购买时长，也不会扣款；需要其他使用安排，请联系现场老板。

## 8. 遇到问题怎么办

先找到对应现象，按顺序处理。老板无法处理时找所属服务商；服务商无法处理时找管理员或系统维护人员。

| 看到的现象 | 先做什么 | 仍未恢复时 |
| --- | --- | --- |
| 账号或密码不正确 | 核对登录账号、大小写和空格，确认使用最近一次修改后的密码 | 老板找服务商，服务商找管理员，检查是否停用或需重置 |
| 登录后没有本店设备 | 清空设备搜索及状态筛选 | 由服务商核对设备归属；不要反复新建同一台设备 |
| 设备离线 | 看控制盒是否通电、店里 WiFi 是否可用；密码改变时按第 6 节换网 | 服务商检查编号、密钥、服务器地址及硬件 |
| 手机连热点后提示无互联网 | 选择继续连接，在浏览器地址栏输入 http://192.168.4.1 | 确认连接的是对应 RentGate-xxxxxx，不是店里 WiFi |
| 配网页打不开 | 确认设备热点还在、手机仍连接它；必要时重新连接后输入完整地址 | 三分钟无操作会关热点；按第 6 节重新进入或联系服务商 |
| 保存后热点消失 | 将手机切回正常网络，回后台看设备是否在线 | 热点重新出现时重新连接，检查 WiFi 密码和验证码 |
| 验证码错误或过期 | 回后台生成新 8 位码，核对开头的 0，在 5 分钟内填写 | 核对选中的后台设备和当前控制盒，交服务商检查 |
| 首页只填 WiFi 无法保存 | 首次配对还需验证码；只换网则进入“手动配置（Config）” | 按第 4 节配对或第 6 节换网 |
| 提示正在配网或配对，不能开机 | 完成配网，或退出配网并作废不用的验证码 | 等后台状态更新；离线设备需现场退出或等待超时 |
| 客人扫码打不开或入口不可用 | 换正常网络测试，检查二维码是否贴错、设备是否已停用 | 服务商核对网址；“仅本机可访问”需维护人员修正后重打 |
| 在线，但不能领免费试用 | 按客人页提示看是否使用中或冷却中 | 服务商再查归属、账号、类型是否启用、试用是否大于 0，以及是否仍在配网/配对 |
| 提示已发送指令或运行中，机器没反应 | 等页面更新，核对最新报到时间和“继电器回报” | 联系服务商检查控制盒及机器；不要反复点放行覆盖时间 |
| 停止后机器仍在通电 | 检查设备是否离线、最新回报是否已更新 | 需要立即停机时由现场人员使用正常电源开关，再找服务商 |
| 提前停止后仍不能试用 | 查看冷却剩余时间；停止不会清除冷却 | 确需使用，由老板决定是否手动放行 |
| 付款按钮不能点、订单为空、收益为 0 | 当前版本没有接入支付，试用和放行都不记收入 | 不需要为此修改商户号或反复建套餐 |
| 提示无权限，或找不到某项菜单 | 在“个人设置”核对角色及所属服务商 | 找上级处理权限范围内的事项，不要借用别人的账号 |

### 联系售后前准备什么

把以下内容提供给服务商，通常能减少来回询问：

1. 门店名称、登录账号，以及出问题的设备名称和编号。
2. 问题发生时间、做了什么操作、页面显示的完整提示。
3. 设备控制台截图，包含连接状态、报到时间、运行剩余时间及回报。
4. 控制盒是否有电、是否换过 WiFi 或密码、是否操作过配对或重设密钥。

截图时遮住密码、配对验证码和设备密钥。实物拆装、接线或控制盒程序更新交给交付人员处理。
