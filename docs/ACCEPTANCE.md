## 规则与限制

冷却按试用计划结束后计算：`cooldown_until = expire_ts + cooldown_minutes × 60`。PRD 部分公式以开始时间计算，与文字定义不一致，本版采用“结束后冷却”。手动控制不会生成订单，也不会重置试用冷却。

使用单实例 H2 文件库存储。升级前停服务备份数据；数据库迁移后回滚旧程序需同时恢复旧备份。实际执行状态须结合硬件回报，服务端运行指令不能代表继电器已经吸合。

## 实物待验

- [ ] 烧录固件，底板独立 5V 供电，确认控制 GPIO 与有效电平。
- [ ] 首次上电自动开热点；手机用固定密码 RentGate888 配网，确认成功后关闭热点、重启保留参数，全程无需串口。
- [ ] 原 WiFi 消失/密码改变，上电和运行中均在连续约 30 秒离线后自动开热点；手机换网时保留设备编号和密钥。
- [ ] 等待超过 180 秒仍能配网；WiFi 密码错误可重新连接热点修改；设备参数错误保持热点，修正保存后可恢复。
- [ ] 热点无人连接时恢复原 WiFi，确认自动重连并关闭热点；手机填表期间不主动重试连接。
- [ ] 后台轮换密钥，收到 401 自动开热点，手机更新密钥后恢复心跳。
- [ ] 真实手机扫码领取 1 分钟试用，确认吸合、到期断开及冷却不可重领。
- [ ] 后台放行/停止/停用，确认下一轮询执行，硬件上报一致。
- [ ] 使用中断开 WiFi，确认原计时仍到期断开；恢复网络后获取最新状态。
- [ ] 运行中重启 ESP，确认先断开，再获取未到期指令。
- [ ] 检查启动瞬态、电源稳定性和继电器抖动。

编译与模拟验证不代表实物已经验收。固件当前只支持 HTTP，网页可通过 HTTPS 代理；长期公网设备接入的 TLS 证书校验需要后续固件扩展。
