# ESP-01S 固件 v0.3.0

目标板 ESP-01S / ESP8266、1 MB Flash。PlatformIO：espressif8266@4.2.1、WiFiManager@2.0.17、ArduinoJson@6.21.5。仅烧录需要电脑，之后用手机配网。

## 烧录

在项目根目录的 PlatformIO 终端执行，COM3 换成实际串口：

```powershell
pio run -d firmware
pio run -d firmware -t upload --upload-port COM3
```

烧录底座切至烧录模式，写入后切回运行模式并重新上电。正常升级不擦除 Flash，会保留旧配置。模拟首次使用可先运行 `pio run -d firmware -t erase --upload-port COM3` 再 Upload，整片擦除也会删除固件、WiFi 和设备配置。

产物 `firmware/.pio/build/esp01_1m/firmware.bin`，烧录地址 `0x0`，LittleFS 为 64 KB 分区。串口 115200，配网不依赖串口。

## 验证码配对

1. 在管理后台选设备，点击“配对”，取得 8 位数字验证码，5 分钟内有效。
2. 手机连接设备热点 `RentGate-xxxxxx`，固定密码 **RentGate888**，浏览器打开 **http://192.168.4.1**，进入 Configure WiFi。
3. 选择 WiFi、填写 WiFi 密码和验证码并保存。服务器地址默认预填当前腾讯云服务器，可修改；设备号和密钥无需填写。
4. 设备联网后凭验证码自动获取设备号、密钥并保存，成功后关闭热点，无需返回后台确认。重新配对成功时原密钥失效。

验证码错误、过期或已被其他设备使用时会保留配置页并显示错误；可重新生成后修改，或取消退出。同一设备可重试取回相同结果，避免响应丢失后重复换钥。待配对请求保存在 pending.json，重启可继续；取消/超时会清除待配对请求，原有效设备配置仅在成功后替换。

## 完整手动配置

**留空验证码**，填写 WiFi、服务器 HTTP 地址、设备编号和 43 字符密钥，再保存。原有手动方式保留，全部参数均可修改。有验证码时以验证码对应的后台设备为准。WiFi 或参数错误时可以返回修改，未保存的原配置可取消恢复。

重设密钥保持立即撤销旧密钥，不自动推送；设备收到 401 后开热点。可手填新密钥，或使用后台新验证码重新配对。后台“查看密钥”只向有该设备权限的账号显示。

## 进入与结束配网

- 网络正常：待机设备在后台点击“进入配网”，下次轮询打开热点。新固件在配网期间继续认证轮询，因此后台可“结束配网”。
- 网络失败：连续约 30 秒连不上已保存 WiFi，会自动开热点；首次缺少配置时直接开热点。
- 页面所有位置都有“取消并关闭热点”与剩余时间；输入、点选等真实操作续期，自动查询状态不续期。**180 秒无操作自动关闭热点**。
- 保存且连接/配对成功后关闭热点。取消/超时不强制保存新参数，优先恢复原网络；关闭后先重连，60 秒仍需配置时可再次自动开热点。完全离线或未配对时，后台指令无法立即送达，使用本地退出/超时。
- 后台结束配网要求 v0.3.0+。旧 v0.2.0 固件轮询和原配对接口保持兼容；新验证码功能需刷入 v0.3.0。

## 继电器与计时

GPIO0 默认低电平吸合，适配常见 ESP-01S 单路继电器底板。上电先关闭继电器，再获取服务器指令。GPIO0 是启动引脚，启动瞬态和继电器有效电平需要实物验证；不要使用 GPIO1 作为继电器输出。

已有放行使用单调时钟计时，断网、自动开热点、关闭热点均不会取消或延长倒计时。Ticker 回调独立于主循环阻塞网络调用，到期断电；配网期间不接受新的通电指令。先用低压验证供电、吸合、到期断开，市电改装由具备资质人员完成。

当前设备通信仍使用 HTTP，验证码限时/单次和数据库加密不能代替传输加密。编译与模拟测试不能代替实机验收。
