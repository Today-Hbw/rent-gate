连接与使用指南

  1. 准备账号与设备

    管理员创建服务商，服务商创建老板账号。设备须分配给老板并选择设备类型，才能开放扫码试用。

  2. 手机配网与配对

    后台点击“配对”生成 8 位验证码。烧录 v0.3.0 固件后，手机连接 RentGate 热点，密码 RentGate888，在 192.168.4.1 填写 WiFi 和验证码并保存，设备号和密钥自动写入。也可留空验证码，手动填写全部信息。

  3. 联网时修改配置

    待机设备点击“进入配网”，连接热点修改配置。可取消退出，3 分钟无操作自动关闭，后台可“结束配网”。断网超过约 30 秒也会自动开热点。“查看密钥”可查看权限内设备密钥，旧设备首次成功连接后可查看。

  4. 配置试用和套餐

    管理员或服务商配置设备类型的试用与冷却分钟数。老板配置对应类型的时长套餐，客人扫码后即可看到。

  5. 打印二维码

    在设备行点击“二维码”，下载贴在机身。二维码只包含客人入口，不包含设备控制密钥。

  6. 现场验证

    先低压测试继电器。设备在线、未运行且冷却结束时，客人可点“免费试用”；设备按本地倒计时自动断电。

手动放行和停止在下次轮询时执行。断网后已有倒计时继续，到期断电。重新配对或重设密钥后，原密钥立即失效。
